2. **Cold-Install `electron@45.0.0` Lazy Binary Download Race in Parallel Vitest Workers:**
   - Because `electron@45.0.0` downloads its binary lazily inside `node_modules/electron/index.js` on the first `require('electron')`, running `vitest run` immediately after a fresh `pnpm install` causes multiple Vitest worker threads to spawn `electron/install.js` concurrently into the same directory on Windows. Running `node -e "import('electron')"` once after `pnpm install` (or mocking `electron` in unit tests that do not need the binary) prevents this first-run race.
3. **Deprecated `pnpm.onlyBuiltDependencies` Key in Root `package.json`:**
   - `pnpm v12.15.0` logs a non-fatal warning that `"pnpm": { "onlyBuiltDependencies": [...] }` in `package.json` is ignored in favor of `allowBuilds` in `pnpm-workspace.yaml` (which is already configured in `pnpm-workspace.yaml`).
